Method

  • Texts: King James Bible, Shakespeare (Hamlet, Macbeth, Romeo and Juliet), U.S. Constitution, Pride and Prejudice, On the Origin of Species (1859). One fixed public-domain edition each, named in every prompt.
  • Tasks: quote a reference; quote the passage that comes next; give a quote on a theme with its location; trick questions where the right answer is "this does not exist".
  • Scoring: every prompt asks for the passage word for word, so a quote is correct only if every word matches the named edition letter for letter (punctuation and capitals ignored; a complete quote followed by extra text still counts). Wrong answers are sorted, approximately, into spelling only, incomplete, altered (word similarity ≥ ), real passage from the wrong place, and made up.
  • Settings: one user message, JSON answer, no tools or web search, temperature 0 where a model accepts it, up to 16,000 output tokens (Llama 4 Maverick: 8,192, its host's maximum), each model's default reasoning. Answers cut off at the earlier 2,000-token limit were asked again at 16,000.
  • Not measured: hallucination in general, paraphrase, or quotation from obscure or private documents. Results hold for the exact model IDs and dates below.
